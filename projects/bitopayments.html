Overview

A production payment gateway that lets merchants accept crypto on EVM chains and Tron. It spans eight services — merchant checkout, admin and merchant dashboards, backend APIs and smart contracts — with settlement and reconciliation handled on-chain and off.

What I built
  • Merchant checkout and a settlement/reconciliation pipeline for EVM chains and Tron.
  • Hardened auth as a reusable baseline: httpOnly cookie sessions, CSRF double-submit, credentialed CORS allow-list and TOTP 2FA.
  • Admin and merchant dashboards; on-chain smart contracts for settlement.
  • Shipped on VPS + Vercel with GitHub Actions → GHCR → docker-compose CI/CD.
Architecture
  • 8-service monorepo behind a NestJS API layer
  • Durable queues decouple the request path from settlement
  • PostgreSQL of record; Cloudflare + Nginx edge
