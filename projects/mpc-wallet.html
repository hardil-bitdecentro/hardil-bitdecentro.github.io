Overview

A B2B custody platform where private keys never exist as a whole. Signing is a threshold-MPC ceremony split across parties, behind a deliberately frozen 'signing seam' so the MPC provider can be swapped without touching product code.

What I built
  • Designed a frozen signing seam — the abstraction that isolates the rest of the system from the MPC engine.
  • Threshold-MPC signing (Go / Taurus), EVM + Bitcoin, multi-tenant key isolation.
  • Configurable per-share key storage across cloud providers.
  • USD-denominated policy engine for approval limits; audited approval trail.
Architecture
  • Signing seam abstracts the MPC engine
  • Per-share key storage split across clouds
  • Policy + approval engine gates every signature
