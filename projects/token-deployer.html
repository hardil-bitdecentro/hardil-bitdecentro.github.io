Token Deployer

Multi-chain ERC-20 / TRC-20 deployer (CLI) with a deployer-only timed-burn expiry model.

Overview

A command-line tool to deploy ERC-20 and TRC-20 tokens across chains, with an unusual deployer-only timed-burn expiry model baked into the contracts — and a Docker-based test suite so contributors need no host Foundry install.

What I built
  • ERC-20 and TRC-20 deployment from one CLI.
  • Deployer-only timed-burn expiry model in the contracts.
  • Foundry contracts with a Docker-only test suite (no host toolchain required).
  • Focused CLI UX for repeatable, auditable deploys.
Architecture
  • CLI → Foundry deploy → multi-chain targets
  • Contracts encode the expiry / burn policy
