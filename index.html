Reference architecture

How a money-critical service is wired — the pattern behind custody, payments, trading and gaming.

Clients
React / Next.js · React Native · browser extension — httpOnly sessions, CSRF, TOTP 2FA
API — NestJS
Typed REST / GraphQL + WebSockets; auth guard; request path kept fast and decoupled
Audited choke-point
Every money / state mutation routes through one audited function; the ledger is truth, caches mirror it
Durable queue
Redis / BullMQ — backpressured, batched writer keeps the hot path off the DB; nothing drops under load
Ledger + database
Append-only, hash-chained & signed ledger (tamper-evident) + PostgreSQL; monotonic sequence, gaps detectable
Custody — MPC
Frozen signing seam; threshold-MPC (Go / Taurus); keys never whole; per-share storage across clouds
Secrets & deploy
Cross-cloud secrets (AWS + GCP) · GHCR → compose / Terraform + ECR · Nginx + Cloudflare TLS
